### Wai Chung's Personal Website
---
Built with Hugo web static framework.

This repository contains the source code for my personal website.

The website is based on [hugo-website](https://github.com/pmichaillat/hugo-website) by [pmichaillat](https://github.com/pmichaillat).

As I was still exploring what I wanted my personal website to look like, for now I decided to adopt a minimal approach and gradually build upon it as my ideas became clearer.
